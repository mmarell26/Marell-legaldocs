# Marell Docs

Professional document-services website for Marell Docs, Philadelphia.

## Current positioning

Marell Docs turns rough notes, screenshots, emails, forms, and unfinished files into polished Word and PDF documents ready to send, print, present, or use. The business is not a law firm and does not provide legal advice or representation.

## Hosting

- Current custom domain: `marelllegaldocs.com`
- The repository works with GitHub Pages and includes `netlify.toml` for Netlify deployment.
- All website pages are static and require no build command.
- The quote page uses the Tally form `9qKPLY`, which must be published before launch.
